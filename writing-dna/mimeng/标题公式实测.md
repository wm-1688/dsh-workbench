# 标题公式实测（289 条样本）

> **数据来源**：仓库的 `refs/标题库.md`。
> **⚠️ 它自称「共收录 1013 条标题」，但实际每节只列了 50 条，正文样本共 289 条。**
> 各节标题里写的条数（212 / 52 / 249 / 399 / 62 / 39）加起来正好 1013，说明**它是有意抽样的**。
> 所以下面是**样本统计**，不是全库统计——但 289 条对模式识别已经足够。
> 可复现：`tools/dna-titles.py`，原始数据 `_meta/titles-stats.json`。

## 一、字数：15 字是靶心

| 区间 | 条数 | 占比 |
|---|---:|---:|
| ≤12 | 62 | 21.5% |
| **13–16** | **121** | **41.9%** |
| 17–20 | 86 | 29.8% |
| 21–25 | 17 | 5.9% |
| >25 | 3 | 1.0% |

**平均 15.3 字，中位 15 字。13–20 字合计占 71.7%，≤20 字占 93.2%。**

**实操含义**：标题写超过 20 字就已经落在她惯用区间的边缘，超过 25 字基本不是这个路子。

## 二、特征命中率（289 条）

| 特征 | 条数 | 占比 |
|---|---:|---:|
| **含「你 / 我 / 我们」** | **154** | **53.3%** |
| 数字 | 52 | 18.0% |
| 极致断言（最 / 永远 / 根本） | 51 | 17.6% |
| 否定 / 劝诫 | 51 | 17.6% |
| 句中含有疑问 | 50 | 17.3% |
| 感叹号 | 49 | 17.0% |
| 问号结尾 | 37 | 12.8% |
| 身份词（男 / 女 / 老公 / 老婆 / 单身） | 35 | 12.1% |
| 婚恋词 | 24 | 8.3% |
| **反差（凭什么 / 竟然 / 居然）** | **4** | **1.4%** |

**「你我代入」以 53.3% 断层第一——超过一半的标题里直接出现「你」或「我」。**

这与 L1 的正文统计完全一致（正文每千字「我」16.9 + 「你」12.5）。**标题和正文用的是同一个机制：把第三人称叙述改成第一、第二人称对话。**

## 三、人工分类经得起校验

仓库把标题分成 6 类。**实测各节的命中率，分类基本站得住**：

| 分节 | 样本数 | 均字数 | 含你我 | 含疑问 | 含否定 |
|---|---:|---:|---:|---:|---:|
| **你我代入型** | 50 | 15.6 | **100.0%** | 0% | 8.0% |
| **疑问挑衅型** | 50 | 14.9 | 58.0% | **92.0%** | 6.0% |
| **否定劝诫型** | 39 | 15.9 | 64.1% | 0% | **92.3%** |
| 数字清单型 | 50 | 16.1 | 50.0% | 8.0% | 4.0% |
| 极致断言型 | 50 | 15.6 | 50.0% | 0% | 0% |
| 其他 | 50 | 14.1 | 0.0% | 0% | 4.0% |

**「你我代入型」100% 命中、「疑问挑衅型」92%、「否定劝诫型」92.3%——三个主类的定义是准的。**

## 四、各分类的真实权重

各节标题里标注的原始条数（合 1013）：

| 分类 | 条数 | 占比 |
|---|---:|---:|
| **你我代入型** | **399** | **39.4%** |
| 其他 | 249 | 24.6% |
| **疑问挑衅型** | **212** | **20.9%** |
| 数字清单型 | 62 | 6.1% |
| 极致断言型 | 52 | 5.1% |
| 否定劝诫型 | 39 | 3.9% |

**「你我代入」+「疑问挑衅」合计 60.3%——这两条公式覆盖了近三分之二的标题。**

## 五、需要修正的一处

仓库的二手 SKILL.md 把「矛盾反差型」列为六大公式之一，并举例《她那么丑，凭什么让王菲大哭？》。

**实测：含「凭什么 / 竟然 / 居然」的标题只有 4/289 = 1.4%。**

**「反差」是他的文章标题里的偶发手法，不是高频公式。** 用它当常规生成模板，会产出和她的实际分布不符的标题。

## 六、可直接用的生成约束

写标题时按这个顺序套：

1. **必须含「你」或「我」**（53.3% 的标题有，目标应是 100%——这是最高杠杆的一条）
2. **字数落在 13–16 字**（占 41.9%），不超过 20 字
3. 在两条主公式里选一条：
   - **你我代入型**：把你 / 我放进一个处境 → 《你会对亲近的人说谢谢吗》
   - **疑问挑衅型**：用问句下判断 → 《我凭什么要相信你？》
4. 需要加力度时用**数字**（18.0%）或**否定劝诫**（17.6%）——**不要用「反差」**（1.4%）
5. ⚠️ **「最」字要避开**——它在 17.6% 的标题里出现，但属于广告法绝对化用语；改用「真的很」「特别」这类副词替代（正文里「就是/特别/真的/其实」是她的口语标记）
