# L2 文章结构模板（咪蒙）

> **置信度：中。** 6 篇逐篇人工标注，覆盖 4 种体裁。**但每类体裁只有 1 篇支持**（清单干货另有《如何写爆款》可交叉印证），所以归纳出的模板是「该体裁的一个样本」，不是「该体裁的常见形态」。
> 逐篇骨架里的引文均已在原文核对；**结构判断来自人工阅读，不是脚本统计**。

## 一、逐篇骨架

### 采访群像型｜《北漂最怕听到的四个字：押一付三》（2017-12-12，4277 字）

- **开头**：直接追问 + 自答，两行完成。「你有没有试过，在网上租房的时候，看看最低价和最高价的房子，分别长什么样子的？／我试过。」
- **第 3 段**：元交代研究动机——「我和同事分别去走访了很多个北漂的住处，然后选取了5个人」
- **张力预置**：一对极值对比并置——「有些人住在6平米的房间里，最大梦想是有一天可以住一房一厅」／「有些人住在2000平米的豪宅里，最大梦想是有一天可以住100平米的小房子」
- **正文**：**房租数字做小标题**（750元／月 → 1600 → 3400 → 2.4万 → 16亿），每格统一执行「人物档案行 → 场景白描 → 一句原话落点 → 固定四问 Q&A」的模块化复制
- **转折**：不在篇中，在**最后一个案例**。前四格是房租阶梯，到 Mark（16亿）完成视角反转——读者以为在看「穷」，结果看的是「门槛」
- **结尾**：撤出故事，判断句 + 反问排比 →「连追梦也有最低消费了」→ 用被访者原话收：「可是，0.0001也比0大啊」

### 影视人物观点型｜《她那么丑，凭什么让王菲大哭？》（2018-11-29，2820 字）

- **开头**：第一人称闹剧 + 立刻自嘲掉价。「千万不要和喜欢的人去看《无名之辈》，你会哭到丑爆」→「在电影院哭得……假睫毛都掉了」→「撸了两个多小时的妆和蓝朋友约会」
- **转折点**：约 1/5 处**明确宣告换轨**——「但我不想再赘述她的演技了，我想说说她和这个世界相处时的态度」
- **正文**：**排比否定式，四段「任素汐不要」逐级升维**。每段同构：现象批判 → 对比组（流量明星）→ 任素汐的拒绝行为 → 数字佐证（一场戏 300 块／600 多场《驴得水》／扇自己 1500 多个耳光）→ 一句原话
- **结尾**：三段递进。借卢梭「剧场效应」上升到时代病灶 →「任素汐，就是那个拒绝站起来的人」→ 三个「凭什么」排比 → 以徐峥「好演员的春天就到了」收希望 → **署名后记交代创作动机**（「发现她的粉丝只有64万时，觉得好心塞」）

### 清单干货型｜《所谓情商高，就是懂得好好说话》（2015-11-22，5179 字）

- **开头**：题记金句（「真正的情商高，不是虚伪，而是温暖」）→ 蔡康永实例 → 朋友反夸她、她拒绝（「不。是。吧。」）→ 自嘲收口「原来我这么屌」
- **正文**：**31 条编号清单**，每条 = 一句可执行的话 + 一个具体人/场景 + 一句点评。素材高度混合（明星／前同事／大学室友／上市公司总裁朋友／书籍）
- **无结构转折**，靠第 31 条后的整体升华升轨
- **结尾**：**反驳式升华**。先立起读者质疑（「很多人说，不喜欢情商高的人，他们虚伪」）再逐句驳掉 → 收缩成一句定义 → 落到利益承诺「智商决定你的下限，情商决定你的上限」

### 常态痛点观点文｜《大多数婚姻不是死于无性，而是死于无话》（2019-01-28，2571 字）

- **开头**：反常识一句话独立成段 + 三层权威背书（艾小羊 → 伍迪·艾伦 → 马伊琍）
- **转折点**：约 2/5 处，从「症状」切到「病因」。前三个小标题全是并列症状，直到「为什么婚姻不会死于无性，却会死于无话？」才开始给机制
- **正文**：症状清单（时间轴倒叙）→ 病因解释 → 双向给建议。「不再说废话了」一节用 **7 个「以前……现在……」对照句**排比，是全篇密度最高的段落
- **结尾**：分层收口 — 先对男生说（「不要觉得你不出轨、不约炮、不嫖娼、不家暴，就是好男人。扯淡」）→ 再对女生说（「还是要经济独立」）→ 以「我要和你说很多很多很多的话」回环标题 → **篇末标注「本文顾问：李松蔚」**

### 情感故事型｜《我是因为你，才爱上了这个世界》（2015-12-21，4315 字）

- **开头**：题记金句 → 编年体锚点（「今天是我的生日。我想记录美好的事」）→ 撒娇式报备
- **正文**：**10 个编号小故事**（已核实：行首数字正好 1–10），每个 150–400 字，全部以对话推动、以吐槽收尾
- **转折点**：**第 10 个故事**。前 9 个是单向的「他为我做了什么」（KTV 一间间敲门、剖腹产后先问老婆、半夜买砂锅粥、雨中送创可贴），第 10 个首次出现「我」的失职——罗同学一直说头痛眼睛痛，她「内心深处，有点嫌他不懂事」，直到他等电梯时晕倒，查出肾性高血压、血压 190 多。全篇由此由甜转愧
- **结尾**：先下沉到自剖（原生家庭、自卑）→ 上浮到金句。末句（已核实为全文最后一行）：「真正爱一个人，是不需要坚持的。是自然而然，想要一直去爱。」

### 方法论自述｜《如何写出阅读量100万+的微信爆款文章？》（2015-11-26，4462 字）

- **开头**：题记（「这件事与你有关，这件事对你有用」）→ 转成朋友对话（「我说，40万啊」「朋友怒了：我擦。你要不要脸啊」）
- **正文**：**12 个编号小标题**，前 11 条技术清单。证据主要是**别人家的标题**，自己的案例只用 4 个
- **结尾**：**推翻自己的方法论**——「最大的技巧都敌不过『走心』两个字」→ 鸡汤式励志 → 以居高临下的反问收：「其实当你问我该写什么的时候，你就不该写」

## 二、可复用模板

### 模板 A：清单干货型
```
题记金句(15-25字) → 第一人称小故事引入(150-250字)
→ 编号 1..N（每条 100-170 字，必须含 1 个具体人名或场景）
→ 反驳读者质疑(100-200字) → 一句话收拢全篇(20-40字) → 篇末划线金句(10-20字)
```
字数配比：**引入 5% ｜ 主体 80% ｜ 升华收尾 15%**

### 模板 B：情感故事型
```
题记金句 → 编年体/纪念日锚点(30-60字)
→ 编号小故事 1..N-1（连续同向叠加，每个 150-400 字，含对话与自嘲落点）
→ 第 N 个故事做方向反转（由"他付出"转为"我失职"）
→ 自剖来源(150-300字) → 金句回环题记
```
字数配比：**锚点 1% ｜ 前段故事 70% ｜ 反转故事 15% ｜ 自剖升华 14%**
**关键约束：反转必须落在 85%–90% 位置，越晚越有效。**

### 模板 C：影视/人物观点型
```
第一人称闹剧开场(100-200字) → 自嘲掉价(20-40字)
→ 声明换轨("我不想再赘述X了，我想说Y")
→ 排比否定段 3-4 段（每段＝现象批判→对比组→主人公的拒绝→数字佐证→原话）
→ 概念升维(引一个理论把个人放大到时代) → 排比泄愤 → 希望收口 → 署名后记
```
字数配比：**闹剧开场 8% ｜ 排比主体 65% ｜ 升维泄愤 20% ｜ 后记 7%**

### 模板 D：采访群像型 ⚠️
```
直接追问读者 → 自答+研究动机 → 一对极值对比预置张力
→ N 个案例格（每格＝数字小标题＋人物档案行＋场景白描＋原话落点＋固定 Q&A）
→ 撤出故事上判断 → 反问排比 → 被访者原话收尾
```
字数配比：**引入 4% ｜ 案例格 85% ｜ 判断收尾 11%**
**⚠️ 仅 1 篇支持，作为「高频模板」使用风险高。**

## 三、跨体裁的共性（这部分置信度较高）

6 篇里有 5 条共同动作，与体裁无关：

1. **题记金句开篇**（5/6 篇有独立题记，且多数在结尾回环复现）
2. **第一人称在场**，且**开场先自曝糗事**（4/6 篇）
3. **小标题要么是编号、要么是人群特征**，不用抽象概念
4. **结尾必有一段"撤出故事"的判断或升华**，不做自然结束
5. **情绪落点用对话或不完整句**，不用感叹号（详见 `语言DNA.md` 与文末证伪）
