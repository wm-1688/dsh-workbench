## 三、流程改造（5 处）

### 改动 1：② 吃透素材 → 加「升华三步」

**依据**：02 讲

> 个人的经历本身不传播，但个人经历传达的共情情绪会传播。

**现状**：只要求「把事实拆出来，逐条列，不许概括」。

**问题**：拆得越细，写的时候越舍不得删，最后变成资料陈列。

**改法**：

```
拆完事实后，必须再做三件事：

1. 写下你自己的具体经历或观察——你与这件事的关联是什么？
   （不是「我关注这件事」，是「我表哥上周也被裁了」这种具体的）

2. 提炼共性——这个具体的事，背后勾的是读者哪根共同的神经？
   （职场、尊严、安全感、公平、家人……）

3. 升华到公共命题——用个人的故事得出一个公共的判断。

三者缺一不可：具体提供真实，公共命题提供共鸣。

只停留在第 1 步 = 私事，不传播。
跳过第 1 步直接讲公共命题 = 空话，没人信。
```

### 改动 2：④ 出骨架前 → 新增「定结构 + 定读者承诺」

**依据**：03 讲

#### 动作 A：定结构类型（强制三选一）

| 结构 | 观点/答案位置 | 依据 |
|---|---|---|
| **故事→观点** | 从故事中段长出来（**40-60%**） | 观点必须从故事中长出来，不能贴上去 |
| **问题→拆解答案** | **答案留到最后（80%+）** | 答案要留到最后，开场讲完结论后面全是废话 |
| **现象→反直觉判断** | 反直觉那步放**中段 50%** | 反直觉那一步是全文爆点 |

⚠️ **上一轮的教训**：曾建议「观点必须前 15%」，那是把三种结构混成一种标准，**错误**。

#### 动作 B：定读者承诺

```
写之前回答三个问题：

1. 标题承诺了什么？读者看到标题，期待读到什么？
2. 我实际给什么？这篇文章真正的内容是什么？
3. 两者一致吗？

判定：如果不一致，停下来改其中一个。

实测反例：#9009 标题写「你赚到了」（承诺：我的钱变多了），
正文写「Anthropic IPO 定价过程」（实际：一家公司怎么上市）。
```

#### 硬标准（对所有结构适用）

```
开头 100 字内不许出现任何正确的废话。
禁词：随着…发展、众所周知、近年来、在当今、不难发现。
```

### 改动 3：⑤ 写正文 → 加「找流失点」要求

**依据**：03 讲 + 2026-11-14 补充答疑

#### 核心方法

**不问「加了几个钩子」，问「读者会在哪几处想走」。**

```
写完之后，从头到尾走一遍，标出读者可能退出的位置：

- 读到哪一段，读者会觉得「我知道后面要说什么了」？
- 读到哪一段，读者会觉得「这段跟我想看的没关系」？
- 读到哪一段，信息停了、节奏平了、没有任何未解的东西？

每一处标记，都是一个必须修的地方。
```

**为什么不用字数指标**：
- 文章长 800 还是 1500 字，需要几个钩子取决于内容本身
- 800 字的故事可能只需 2 个（转折 + 结尾）
- 硬凑的结果一定是假钩子

#### 「读者会不会走」怎么判：五条具体判据

方法：假设读者已经读完这一段，问「他凭什么继续读下去」。**说不出理由，他就会走。**

| # | 判据 | 怎么查 | 来源 |
|---|---|---|---|
| **1** | 有没有「未完成」 | 问题悬着？冲突没解？细节没接上？ | 03 讲悬念定义 |
| **2** | 给的是新东西还是重复 | 读完多知道了什么？可预测 = 会走 | 03 讲诊断反例 |
| **3** | **能不能删** | 真删掉，读者漏什么？没漏 = 该删 | 03 讲密度标准 |
| **4** | 属于「五种非钩子」哪一类 | 连中两类 = 危险 | 大小姐列的五类 |
| **5** | 朗读测试 | 念出来顺不顺？像人话吗？很平吗？ | 04 讲 |

**组合规则**：五条中三条以上 = 这一段必须重写或删掉。

##### 判据 1 详解：有没有「未完成」

> 大小姐对悬念的定义：可以是一个**问题还没有回答完**，一个**冲突还没有解决掉**，一个**细节还没有接上**。

⛔ **「悬着」不等于「问了句问号」**。反例：「这是为什么呢？让我们接着看。」——问了，但没制造悬念。

##### 判据 2 详解：新东西还是重复

> 大小姐诊断反例原话：「读到第二段，读者已经知道后面还是在讲他省钱，**没有非看下去不可的理由**。」

| 答案 | 判断 |
|---|---|
| 一个新事实 / 新角度 | ✅ 有理由继续 |
| 前一段说过的换说法 / 可预测 | ❌ 会走 |

##### 判据 3 详解：能不能删（最硬）

> 大小姐的密度标准：**删掉任何一句话，都会影响读者理解。**

```
随便挑一段，试着删掉它，问：读者会漏掉什么？

- 漏了关键信息 → 留下
- 什么都没漏 → 这一段该删
```

**一个段落删了也不影响，读者读它就是在浪费时间——这正是「会走」的位置。**

##### 判据 4 详解：五种非钩子

| 类型 | 例子（大小姐的反例） |
|---|---|
| 背景介绍 | 「我爸今年六十二，退休三年」 |
| 性格说明 | 「他这一辈子花钱都谨慎」 |
| 原因解释 | 「他说利息稳当，用着踏实」 |
| 补充说明 | 「他也不是不肯花钱」 |
| 总结判断 | 「老一辈苦惯了，有钱才睡得着」 |

**这五类是「会走」的高危区。连续出现两类以上，就是危险段落。**

##### 判据 5 详解：朗读测试

> 04 讲：**读比看更容易暴露问题。**

- 念到一半觉得「这不像人话」 → 会走
- 念着很顺但很平 → 也可能走（平 = 没有起伏）

##### 实例：用五条判据诊断 9009

原文（节选）：

> Anthropic 是今年 10 月 26 号向 SEC 递的招股书，335 页，代码 ANT，计划上纳斯达克全球精选市场……认购需求接近发行规模的七倍。

| 判据 | 结果 |
|---|---|
| 1. 删掉会漏关键信息吗？ | **不会**——招股书几页、代码是什么，不影响理解全文 |
| 2. 多知道了什么？ | 知道了流程，但**和「你的钱被谁决定」这个主题无关** |
| 3. 有东西悬着吗？ | 没有 |
| 4. 属于哪一类？ | **背景介绍 + 补充说明**（连中两类） |
| 5. 念出来顺吗？ | 顺，但很平 |

**5 条里 4 条命中 → 必须重写或删掉。**

#### 钩子只能是三种

| 类型 | 定义 |
|---|---|
| **悬念** | 留一个问题没答 |
| **反转** | 推翻前面的预期 |
| **新信息** | 给一个读者不知道的事实 |

#### 开头钩子 vs 中段钩子

> 开头那个钩子，是钩读者**要不要点开**。
> 中段再放一个小钩子，是钩读者**要不要继续看下去**。

**职能不能互相替代**——开头写得再好，中段垮了读者照样走。

#### 参考经验值（不是标准）

大小姐举例时提过：

> 一篇一千字左右的文章，去掉开头结尾，中间约八百字，分成四段，每段两百字上下，正好四个钩子位。

**这段话是举例，不是指标。** 三个词要注意：

| 原话 | 性质 |
|---|---|
| 「一千字**左右**」 | 举例 |
| 「两百字**上下**」 | 约数 |
| 「**正好**四个钩子位」 | 这个案例的结果 |

**不能反过来当公式套**：
- 不要求「必须达到 N 个」
- 不因为没凑够数就去加内容

**判断标准永远是「读者会不会走」，不是「凑没凑够」。**

### 改动 3 附：完整示例（大小姐原案）

**案例**：`我爸偷偷把退休金存成了三年定期`

#### ❌ 反例：中段垮掉的样子

> 我爸今年六十二，退休三年。他每个月四千多退休金，平时也省，买菜都赶傍晚超市打折。最近他去银行，把攒的钱存成了三年定期。他这一辈子花钱都谨慎，不爱冒险，我妈也说他人心就这脾气。我问他为啥定期，他说利息稳当，用着踏实。他也不是不肯花钱，家里该添的都添了，就是自己身上舍不得。老一辈以前苦惯了，手里有钱才睡得着。

**逐句诊断**：

| 句子 | 属于哪类 | 读者会不会走 |
|---|---|---|
| 我爸今年六十二…存成三年定期 | 背景交代 | 会 |
| 他这一辈子花钱都谨慎… | 性格说明 | 会 |
| 我问他为啥定期，他说利息稳当 | 原因解释 | 会 |
| 他也不是不肯花钱… | 补充说明 | 会 |
| 老一辈苦惯了… | 总结判断 | 会 |

**大小姐评语**：

> 这个整段应该都能看出来问题，都是背景介绍和性格说明，没有一件事吊着读者。读到第二段，读者已经知道后面还是在讲他省钱，没有非看下去不可的理由，**这就是中段垮掉的样子**。

#### ✅ 正例：四处「读者不会走」的设计

**位置 1（开头）—— 悬念**

> 我一开始以为，这又是老一辈舍不得花钱的老毛病。直到那天陪他去银行，才发现事情不是我想的那样。他填单子的时候手很稳，不像是临时起意。

手法：先立「你以为的」，再推翻它。

**位置 2 —— 反转**

> 我回家翻他的存折，本来想劝他留点活钱。可看完我没说话。其实这笔钱他早就想好了，利息、到期日、哪一年能取，一项项写在本子边上，比我算房贷还清楚。

手法：预期「我要劝他」，实际「看完我没说话」。

**位置 3 —— 新信息**

> 更让我意外的是，这笔钱他没打算给自己花。本子夹层里夹着两张纸条，写着两笔去处，一笔是给孙子的教育，另一笔，字迹我看了半天没认出来。

手法：给新事实，同时埋新疑问（另一笔字迹是谁的）。

**位置 4 —— 再给悬念，然后收尾**

> 我拿着纸条去问我妈，她沉默了一会儿才说，那笔钱是留给他一个老战友的。那个战友当年替他挡过事，这些年他家里困难，爸一直记着。

手法：解答前面的悬念，同时给情感落点。

#### 结尾要求

> 大小姐原话：结尾一定要兑现，**不要用完了读者就忘了**。结尾也**不需要破题**。

**做两件事**：兑现前面埋的钩子、给一个落点。
**不做三件事**：不说「这说明了一个道理」、不总结全文、不升华。

### 改动 4：⑦ 自检 → 升级为「三遍修改 + 去 AI 化」

**依据**：04 讲（三遍修改法）+ 05 讲（AI 五特征）

**现有自检**（保留）：事实准确性、结构合规、风格禁忌、论点一致性。

**新增三组**：

#### A. 流失点排查（最重要）

依据改动 3 的五条判据，逐段过一遍。

```
五条判据里中三条以上 = 这一段必须重写或删掉。
```

**自检报告必须写清楚**：哪几段被判为危险、各自的理由、怎么改的。

⛔ **不许只写「已检查，无问题」——说不出具体段落就是没检查。**

#### B. 三遍修改法

| 遍 | 改什么 | 判据 |
|---|---|---|
| 第一遍 | **改结构** | 悬念立住了吗？信息有增量吗？结尾有动作吗？ |
| 第二遍 | **改质感** | 形容词该换动作的换了吗？细节放错方向了吗？ |
| 第三遍 | **改文气** | 朗读一遍：顺不顺？有没有不像你的句子？语气统一吗？ |
| 最后 | **删** | 删掉所有「删了也不可惜」的句子 |

#### C. 去 AI 化五特征

| # | 特征 | 动作 |
|---|---|---|
| 1 | 句长高度均匀 | 刻意制造长短交替 |
| 2 | 结构极度对称（三点式） | 打破，可两点、一点、三加一 |
| 3 | 观点四平八稳 | 换成「我就觉得」「我不同意」 |
| 4 | 举例抽象泛化 | 把「有的人」换成具体的人 |
| 5 | 缺少情绪残留 | 留一点真实的跳脱 |

---

### 改动 5：⑧ 结尾规范

**依据**：03 讲

> 大部分文章的结尾是总结全文，这是最浪费的结尾。

```
结尾三选一：

1. 情绪收缩——让读者心里咯噔一下
2. 值得回味的观点——让他想再读一遍
3. 可转发的点——替读者说完他心里的话

禁止：总之、综上、所以说、总结一下、总而言之
```

### 4.2 补充：语言指纹章节内容

```markdown
## 语言指纹

每个成熟的写作者都有一套稳定的语言指纹：
爱用的句式、特有的连接词、独有的口语颗粒、对标的偏好。

这就是你的辨识度。

三个找法：
1. 读自己的旧文章，标出最有你味道的句子，看它们的共性
2. 观察自己说话的习惯：口头禅是什么？讲事的顺序是什么？
3. 写一封给朋友的信——不端着、不演示，用最真实的语气写

注意：语言指纹不是故意学某个作家，而是在大量真实写作中，
你自己的偏好自然沉淀。它不追求与众不同，因为它本身就是与众不同的。
```

#### 一、分发系统（01 讲）

| 行为信号 | 写作动作 |

#### 二、选题四维（02 讲）

| 维度 | 判据 |
|---|---|
| 情绪势能 | 精准触碰读者没有出口的感受（不是煽情） |
| 差异化 | 这事不是我来写，是不是就没人写出这味道来 |
| 受众基数 | 不太窄也不太宽 |
| 时效窗口 | 长期高、热点短但爆发强 |

**及格**：情绪 或 受众 有一个高分
**优秀**：及格 且 有差异化

| 军事历史 | 记忆与尊严 | 写人不写事 / 细节要真 / 克制抒情 |

| 情感文 | 共情不是煽情 | 写细节不写结论 / 留白 / 拒绝说教 |

### 附录 A：与上一轮方案的差异

| 项 | 上一轮（已推翻） | 本轮 |
|---|---|---|
| 观点位置 | 统一「前 15%」 | **按结构类型定**（故事 40-60%、问答 80%+、反直觉 50%） |
| 核心问题 | 观点埋太深 | **找不到「读者会走」的位置** |
| 钩子判据 | 「每 200 字一个」 | **五条具体判据，不看字数** |
| 风格库 | 认为需要整个重写 | **MS-008 只需剥杂物 + 补一条** |
| Skill 定位 | 替代现有技能 | **方法论层，不替代** |

**推翻的原因**：读了 01-09 讲完整课程后，发现之前只凭 10 篇文章倒推，依据不足。03 讲明确说「答案要留到最后」，而「前 15%」直接违反了它。

### 附录 B：一条重要教训

> **不要把课程里的举例当成公式。**

大小姐讲课大量用具体案例（「一篇一千字左右的文章……正好四个钩子位」），
**案例里的数字是帮理解的，不是标准**。

我们一度把「每 200 字一个钩子」写成公式，结果会导致硬凑假钩子、字数绑死、节奏僵硬。
现在改成「找流失点」，判据是「读者会不会走」，不是「够不够数」。
